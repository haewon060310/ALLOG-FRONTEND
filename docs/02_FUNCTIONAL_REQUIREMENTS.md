# 기능 요구사항

## FR-01 가입·온보딩

- 회원가입과 로그인
- 루틴, 생활 패턴, 목표량, 수행 시간대 입력
- 경쟁 강도와 선호 그룹 인원 입력
- AI 코칭 성향 선택
- 인증 공개 범위 및 개인정보 동의
- 완료 후 초기 하트 3개 지급

## FR-02 AI 그룹 추천

- 목표, 시간대, 난이도, 경쟁 성향, 과거 성공률, 빈자리 기반 추천
- 단순 매칭률보다 추천 이유 제공
- AI 실패 시 규칙 기반 추천 제공

## FR-03 그룹 탐색

- 카테고리, 기간, 난이도, 하트 비용, 모집 인원, 시작일, 인증 방식 필터

## FR-04 그룹 개설

- 이름, 소개, 루틴, 목표량, 기간, 인원
- 공개 범위, 인증 방식, 성공 기준, 경쟁 강도
- 예약 시작 또는 빠른 시작 설정
- 위험 목표와 허용되지 않은 규칙 차단

## FR-05 그룹 참가

- 자격, 정원, 중복 참여, 하트 확인
- 참가 확정 시 하트 예약
- 멤버십 생성
- 시작 전 취소 정책 적용

## FR-06 그룹 운영

- 그룹 공동 목표
- 그룹원 인증 현황
- 고정 분모 성공률
- 개인 순위와 점수 근거
- 예상 보상
- 남은 기간
- 응원 기능
- 무활동 상태 표시

## FR-07 루틴 인증

- 사진 또는 활동 체크 제출
- AI 비동기 분석
- 판정 근거와 신뢰도 제공
- 임시 승인, 추가 확인, 재인증 요청
- 중복·재사용 탐지

## FR-08 신고·이의 제기

- 신고 사유 선택
- 신고 상태 조회
- 재인증
- 이의 제기
- 운영자 검토
- 최종 승인·반려
- 신고 악용 감지

## FR-09 AI 코칭

- 개인 달성률, 순위 차이, 그룹 성공률, 미인증 인원, 마감 시간 사용
- 지금 해야 할 행동 한 가지 제안
- 실제 존재하는 보상과 점수만 설명
- 비난, 조롱, 의료적 표현 금지

## FR-10 순위·보상

- 100점 기준 계산
- 점수 근거 제공
- 그룹 성공률 계산
- 예상 보상과 최종 보상 분리
- 점수 정책 버전 기록

## FR-11 챌린지 종료

- 신고·재검토 대기
- 미처리 인증 검토
- 최종 순위와 성공률 확정
- 하트 및 포인트 원장 기록
- 다음 그룹 추천

## FR-12 리워드 사용

- 포인트 잔액
- 획득·사용 내역
- AAC 쿠폰 목록과 교환

## FR-13 프로필·설정

- 챌린지 기록
- 성공률과 최고 순위
- 코칭 성향
- 알림 설정
- 개인정보와 인증 공개 범위

## FR-14 알림

- 인증 마감
- 순위 변화
- 그룹 성공 구간
- 재인증 요청
- 정산 완료
- 재도전 미션

## FR-15 운영 관리

- 인증과 신고 검토
- 최종 판정
- 사용자 제재
- 그룹 취소
- 리워드 제한
- 자산 조정
- 감사 로그
