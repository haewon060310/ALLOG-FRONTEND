# 신뢰와 안전

## 개인정보

- 얼굴 자동 블러와 배경 흐림 제공
- 인증 공개 범위 설정
- 비공개 AI 인증 모드
- 원본 보관 기간과 삭제 정책 안내
- 위치 정보 최소 수집
- 영상 대신 활동 데이터 또는 대체 인증 허용
- 원본과 공개용 블러 이미지를 분리 저장

## AI 판정

- AI 판정 근거와 신뢰도 제공
- 불확실한 판정은 재인증 또는 운영자 검토로 전환
- AI 결과만으로 즉시 계정 제재 또는 보상 몰수 금지
- 최종 판정 이력 보존
- 정책 버전 기록

## 커뮤니티

- 응원 중심 상호작용
- 조롱, 압박, 공개 비난 금지
- 신고는 재검토 요청으로 처리
- 집단 신고만으로 자동 반려하지 않음
- 신고 악용 사용자는 제한

## 건강 안전

- 의료 진단과 치료 결정 제공 금지
- 위험하거나 과도한 목표 차단
- 증상, 질환, 극단적 식단과 관련된 요청은 안전 안내
- 사용자가 수행하기 어려우면 대체 목표 제안

## 운영자 권한

- 운영자 판정은 이유 코드 필수
- 하트·포인트 수동 조정은 감사 로그 필수
- 모든 운영자 쓰기 작업에 actorId 저장
- before/after 상태 저장

## 프론트엔드 주의

- 토큰을 코드에 하드코딩하지 않는다.
- `.env`를 Git에 커밋하지 않는다.
- 사용자 파일 URL을 영구 공개 링크로 가정하지 않는다.
- 민감한 AI 판정 원문을 다른 그룹원에게 그대로 노출하지 않는다.
