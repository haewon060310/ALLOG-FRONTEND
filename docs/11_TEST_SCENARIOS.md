# 테스트 시나리오

## T01 정상 참가

1. 하트 3개 사용자
2. 모집 중 그룹 참가
3. 멤버십 생성
4. 하트 1개 예약
5. 사용 가능 2, 예약 1 확인

예상:

- 중복 참가 없음
- 예약 거래 1건

## T02 중복 참가

1. 같은 사용자가 같은 그룹에 다시 참가

예상:

- `ALREADY_JOINED`
- 하트 추가 예약 없음

## T03 모집 실패 반환

1. 하트 예약 후 그룹 모집 실패
2. 실패 처리를 두 번 호출

예상:

- 예약은 한 번만 반환
- 최종 잔액 정확
- 동일 결과 반환

## T04 예약 시작형 조건

1. 최소 인원 충족
2. 시작일 전 시작 요청

예상:

- `GROUP_NOT_READY`

3. 시작일 도달 후 요청

예상:

- 그룹 `ACTIVE`
- 예약 하트 `SPENT`

## T05 빠른 시작

1. 최소 인원 충족
2. 일부 참가자 미동의

예상:

- 시작 불가

3. 동의 완료

예상:

- 시작 가능

## T06 AI 임시 승인

1. 인증 제출
2. `ANALYZING`
3. AI 결과 `PROVISIONALLY_APPROVED`

예상:

- 임시 점수 반영
- 하트·포인트 확정 지급 없음

## T07 재인증

1. AI 결과 `RESUBMISSION_REQUIRED`
2. 새 자료 제출
3. 최종 승인

예상:

- 원래 인증일 기준 연속 기록 복구

## T08 신고 후 반려

1. 임시 승인
2. 신고
3. 운영자 최종 반려

예상:

- 인증 점수 제거
- 순위 재계산
- 그룹 성공률 재계산
- 예상 보상 재계산

## T09 무활동 사용자

1. 5명 그룹
2. 1명 전체 기간 미인증

예상:

- 전체 인증 슬롯은 35 유지
- 무활동자 개인·공동 보상 미지급
- 분모에서 제외되지 않음

## T10 최종 정산 멱등성

1. 동일 idempotency key로 정산 두 번 요청

예상:

- 같은 settlementId
- 원장 중복 생성 없음

## T11 재도전 자격

1. 하트 0, 예약 0, 제재 없음
2. 최근 7일 재도전 지급 없음

예상:

- 미션 생성 가능

## T12 재도전 중복 지급

1. 완료된 미션 reward API 두 번 호출

예상:

- 하트 1개만 지급
- 두 번째 요청은 같은 결과 또는 `RETRY_ALREADY_REWARDED`

## T13 AI 타임아웃

1. AI 응답 지연

예상:

- `AI_TIMEOUT`
- 인증은 `ANALYZING` 유지
- 재시도 가능
- 사용자에게 즉시 실패로 표시하지 않음

## T14 신고 악용

1. 같은 사용자가 반복 허위 신고

예상:

- 신고 신뢰도 하락
- 신고 제한 가능
- 순위 점수 변화 없음
