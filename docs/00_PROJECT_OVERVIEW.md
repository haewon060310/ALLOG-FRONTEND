# 프로젝트 개요

## 서비스명

ALLOG(알로그)

## 한 줄 정의

회원가입으로 받은 하트를 예약해 웰니스 그룹 챌린지에 참가하고, AI 인증·재심·그룹 상황 기반 코칭을 통해 경쟁·협력하며 루틴을 지속하는 그룹형 AI 웰니스 게임이다.

## 핵심 문제

사용자는 건강한 루틴의 필요성을 알지만 다음 이유로 장기간 지속하지 못한다.

- 혼자 수행해 책임감이 약하다.
- 기록과 알림만으로 행동 직전의 결정을 바꾸기 어렵다.
- 실패 후 다시 시작할 장치가 부족하다.
- 실제로 체감할 보상이 부족하다.
- 같은 목표를 가진 사람과의 소속감이 부족하다.

## 핵심 해결 방식

- 하트를 사용한 참가 책임
- 개인 순위와 그룹 공동 성공률
- AI 인증 심판과 판정 근거
- 신고, 재인증, 이의 제기, 운영자 검토
- 그룹 상황 기반 AI 코칭
- AAC 포인트와 쿠폰 보상
- 실패 원인 분석 후 AI 재도전

## MVP 대표 챌린지

- 주제: 7일 수분 루틴 그룹전
- 인원: 5명
- 참가 비용: 하트 1개
- 인증: 물병 사진 또는 섭취 체크
- 공동 성공 기준: 그룹 공동 인증률 80%
- 하트 재획득: 그룹 성공 + 개인 7일 중 4일 이상 유효 인증
- 데이터: 실제 사용자 1명 + 가상 그룹원 4명 사용 가능

## 핵심 서비스 루프

```text
회원가입
→ 초기 하트 지급
→ 그룹 추천·탐색
→ 하트 예약
→ 그룹 시작·하트 차감
→ 일일 루틴 수행
→ AI 인증
→ 개인 순위·그룹 성공률 반영
→ AI 코칭·신고·재심
→ 최종 정산
→ 하트·포인트 지급
→ 쿠폰 사용
→ 다음 그룹 또는 AI 재도전
```

## 개발 목표

사용자가 한 번의 인증이 다음 항목과 연결된다는 것을 체감해야 한다.

- 개인 점수와 순위
- 그룹 공동 성공률
- AI 코칭
- 신고와 재심
- 하트 재획득
- 리워드 포인트
- 다음 챌린지 참여
