# 서비스 정책

## 1. 하트 정책

### 역할

하트는 그룹 챌린지 참가권이다.

### 기본 규칙

- 온보딩 완료 시 하트 3개 지급
- 그룹 참가 확정 시 하트 1개 예약
- 챌린지 실제 시작 시 예약 하트 최종 차감
- 모집 실패 또는 운영자 취소 시 예약 해제 및 반환
- 시작 후 자발적 이탈 시 반환하지 않음
- 하트는 현금, 포인트, 상품으로 전환할 수 없음
- 사용자 간 전송 불가

### 하트 상태

```text
AVAILABLE
RESERVED
SPENT
RETURNED
EXPIRED
```

### 트랜잭션 원칙

- 그룹 참가 확정 + 하트 예약은 하나의 트랜잭션
- 그룹 시작 + 예약 하트 차감은 하나의 트랜잭션
- 모집 실패 + 예약 하트 반환은 하나의 트랜잭션

## 2. 하트 재획득

다음 두 조건을 모두 충족하면 하트 1개를 지급한다.

- 그룹 공동 인증률 80% 이상
- 개인 7일 중 최소 4일 유효 인증

## 3. 하트 소진 사용자 재도전

### 자격

- 사용 가능 하트 0개
- 예약 하트 없음
- 최근 7일 내 재도전 하트 미지급
- 부정 인증 또는 운영 제재 상태가 아님

### 미션

1. 이전 챌린지 AI 종료 리포트 확인
2. 실패 원인 확인 또는 선택
3. 다음 목표량·마감 시간·난이도 조정
4. 하루 사전 루틴 체크 완료
5. 라이트 그룹 전용 하트 1개 지급

### 제한

- 7일에 최대 1회
- 재도전 하트 지급 후 최대 보유량 1개
- 반복 이탈·부정 인증·신고 악용 사용자는 제한 가능

## 4. 그룹 시작 정책

### 예약 시작형

```text
시작일 도달 AND 최소 모집 인원 충족
```

### 빠른 시작형

```text
최소 모집 인원 충족 AND 참가자 조기 시작 동의 완료
```

### 모집 실패

- 모집 기간은 최대 1회 연장 가능
- 유사 그룹 이동 제안 가능
- 취소 시 예약 하트 반환

## 5. 그룹 성공률

### 계산식

```text
그룹 공동 인증률
= 전체 유효 인증 수
÷ 챌린지 시작 시 확정된 전체 인증 가능 횟수
× 100
```

5명, 7일이면 전체 인증 가능 횟수는 35회다.

### 분모 정책

- 시작 시점의 인원과 인증 슬롯을 고정한다.
- 자발적 이탈 또는 단순 미인증 사용자는 분모에서 제외하지 않는다.
- 시스템 오류나 운영자에 의해 참여 자체가 무효화된 경우에만 분모 재계산 가능

## 6. 무활동 사용자

권장 기준:

- 연속 3일 미인증
- 또는 7일 중 유효 인증 2회 미만

처리:

- 개인 보상 미지급
- 공동 보상 미지급
- 하트 재획득 불가
- 상위 난이도 그룹 참가 제한 가능
- 다음 추천에서 낮은 난이도 우선

## 7. 점수 정책

```text
개인 목표 달성률       45점
정시 인증률           15점
연속 성공 기록        15점
인증 신뢰도           10점
그룹 공동 목표 기여   10점
응원 및 참여 활동      5점
합계                 100점
```

### 연속 성공 점수

```text
1일: 3점
2일: 5점
3일: 8점
4일: 10점
5일: 12점
6일 이상: 15점
```

- 일반 미인증 시 연속 기록 초기화
- AI 처리 지연은 기록 유지
- 재인증이 최종 승인되면 원래 인증일 기준 복구
- 보상 배율 기능은 사용하지 않음

## 8. 신고 정책

- 신고는 재검토 요청이며 즉시 제재가 아님
- 신고 정확도는 공개 순위 점수에 포함하지 않음
- 신고 이력은 내부 신뢰도와 악용 탐지에만 사용
- 반복 허위 신고는 쿨다운 또는 신고 제한 가능

## 9. 보상 확정

- 임시 승인 결과는 실시간 순위와 예상 보상에만 반영
- 하트와 포인트는 최종 승인 및 최종 정산 후 지급
- 정산은 중복 실행해도 동일한 결과를 반환해야 함
