# 사용자 흐름

## 정상 흐름

```text
회원가입
→ 온보딩
→ 하트 3개 지급
→ AI 그룹 추천 또는 직접 탐색
→ 그룹 상세 확인
→ 그룹 참가
→ 하트 예약
→ 시작 조건 충족
→ 챌린지 시작
→ 예약 하트 차감
→ 일일 인증 제출
→ AI 분석
→ 임시 승인
→ 순위·성공률 임시 반영
→ AI 코칭
→ 챌린지 종료
→ 신고·재검토 대기
→ 최종 정산
→ 하트·포인트 지급
→ 쿠폰 교환
→ 다음 그룹 참가
```

## 그룹 모집 실패

```text
그룹 참가
→ 하트 예약
→ 시작일까지 최소 인원 미달
→ 모집 1회 연장 또는 그룹 취소
→ 취소 시 하트 예약 해제
→ 유사 그룹 추천
```

## 인증 불확실

```text
인증 제출
→ AI 분석
→ NEEDS_REVIEW 또는 RESUBMISSION_REQUIRED
→ 사용자가 재인증
→ AI 재분석
→ 임시 승인 또는 운영자 검토
→ 최종 판정
```

## 임시 승인 후 신고

```text
PROVISIONALLY_APPROVED
→ 다른 사용자가 신고
→ 자동 재검토
→ 필요 시 재인증 요청
→ 운영자 검토
→ FINAL_APPROVED 또는 FINAL_REJECTED
→ 점수·성공률 재계산
```

## 최종 반려

```text
FINAL_REJECTED
→ 해당 인증 점수 제거
→ 개인 점수 재계산
→ 순위 재계산
→ 그룹 성공률 재계산
→ 예상 보상 재계산
```

## 하트 소진

```text
하트 0개
→ 재도전 자격 확인
→ AI 실패 분석
→ 목표 조정
→ 사전 루틴 체크
→ 재도전 하트 지급
→ 라이트 그룹 추천
```

## 복귀 사용자

```text
재접속
→ 이전 기록과 실패 원인 표시
→ 현재 수준에 맞는 목표 추천
→ 참여 가능한 그룹 또는 재도전 미션 제안
```
